### 🧠 Core Competencies & Architecture Philosophy

- 🤖 **Agentic AI & Multi-Agent Systems**: Designing deterministic and autonomous agent topologies using **CrewAI**, **LangGraph**, and **LangChain** with custom tool orchestration, hierarchical manager delegation, and state-machine recovery.
- ⚡ **LLM Integration & Cognitive Pipelines**: Deep experience integrating state-of-the-art models (OpenAI, Gemini, Anthropic, GLM, DeepSeek) with custom token routing, streaming fallbacks, structured JSON extraction via Pydantic/Zod, and offline heuristic evaluation engines.
- 🏗️ **Distributed Full-Stack Systems**: High-concurrency async backends (**FastAPI**, **Express**, **Node.js**) paired with responsive, reactive frontends (**Angular**, **React**, **Next.js**) and real-time WebSocket communication channels.
- 🔍 **RAG & Vector Search**: Hybrid dense/sparse retrieval architectures, semantic embeddings, knowledge graphs, and persistent vector databases (**ChromaDB**, **Pinecone**, **MongoDB Atlas Search**).
- 🛡️ **DevOps & Clean Architecture**: Strict separation of concerns, containerization (**Docker**, **Kubernetes**), test-driven reliability (**pytest**, **vitest**), and automated CI/CD pipeline automation.
